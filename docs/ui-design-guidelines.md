# UI design guidelines

PTO is a friendly, social predictions game. The interface should make it easy
to enter predictions, follow gameweek progress, and compare standings.

When adding a feature:

- **Follow established patterns.** Reuse page layouts, navigation, controls,
  and visual styles rather than introducing one-off treatments. If no pattern
  exists yet, choose a simple, reusable approach and apply it consistently.
- **Make information easy to scan.** Use clear hierarchy and plain labels to
  highlight the matches, gameweek details, scores, and actions that matter.
- **Keep styling clear and restrained.** Use typography and color consistently,
  maintain readable contrast, and never rely on color alone to communicate
  status.
- **Make interactions predictable.** Similar actions should look and behave
  alike. Give clear feedback for loading, saving, success, and errors.
- **Design for different needs and screens.** Use semantic, keyboard-operable
  controls with visible focus. Adapt layouts for narrow screens without hiding
  essential information.
- **Add complexity only when needed.** Prefer simple, reusable solutions over
  decorative or feature-specific exceptions.
